# YogaAI

AI-assisted yoga training and posture analysis system based on MediaPipe.

---

## Environment

- OS: Windows 10 / 11
- Python: 3.10
- NumPy: 1.26.4
- OpenCV: 4.10.0.84
- MediaPipe: 0.10.9

---

## Installation

```bash
conda create -n Yoga_AI python=3.10 -y
conda activate Yoga_AI
pip install -r requirements.txt
